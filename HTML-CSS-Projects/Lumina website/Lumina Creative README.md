# Lumina Creative

A modern and responsive creative agency website built using **HTML5 and CSS3**.

Lumina Creative is a multi-page website designed to present a creative agency and its services through a clean, minimal, and responsive layout.

## 📱 Responsive Design

The website adapts to different screen sizes using CSS media queries.

At smaller screen sizes:

- Navigation elements are reorganized vertically.
- Footer content becomes vertically aligned.
- Services and team sections switch to a column layout.
- Gallery items adjust from three columns to two.
- Hero section height and typography are reduced.
