# Bono Landing Page

A modern and responsive **coming soon landing page** for the Bono Web App, built using **HTML5 and CSS3**.

The project focuses on creating a clean landing page that introduces an upcoming web application and provides users with a simple contact form to submit their information and feedback.

## 📱 Responsive Design

The layout adapts to smaller screen sizes using CSS Media Queries.

On mobile devices:

- The header switches to a vertical layout.
- Contact information is reorganized.
- The main content changes from a two-column layout to a single-column layout.
- The form and text container occupy the full available width.
- The heading size is reduced.
- The supporting paragraph is hidden to keep the mobile layout concise.
